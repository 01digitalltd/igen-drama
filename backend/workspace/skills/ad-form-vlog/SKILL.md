# 形式：Vlog

仅当 `ad_form=vlog` 时生效。

## 核心

用一条 **出镜人自己的 Vlog** 带出她看到的现场。主角是对着观众说话的出镜人。观众就是这台镜头，她看着镜头说话。画面里不要出现相机、手机、摄录机或稳定器，也不要画她拿着这些设备在拍。「手持镜头」是机位，不是道具。现场、景物、她正在看或用的东西是这台镜头看出去的画面，下一段必须切回她。

这不是产品空镜，也不是第三人称短剧。不要改成产品空镜集锦，也不要写成两人演一场戏。一场广告讲完她这条记录。

## 改写

- 保留原文的 Vlog 顺序：开场对镜头介绍、切到现场、切回她的反应、结尾对镜头把原稿要观众做的事说完
- 每一小句的事实都要留下：谁、动作、对象，以及这句写出的品质、比较、条件、否定或要观众做的事。可以改口语，不能改成空泛反应。一句里连续几个动作，每个都要留下。不要插入原文没有的动作或空镜
- 原稿写了手持镜头、自拍或对着镜头时，保留这些字，并写成机位：她看着镜头，或这一镜就是镜头看出去的景物。不要写成手里拿着一台相机
- 台词是她对观众说的：`角色名：（对镜头）…`。不要改成画外「旁白：」，也不要改成角色之间的短剧对白
- 开场先看到她对镜头，不要先进入第三人称冲突（那是短剧宣传）
- 不要改成产品空镜、包装英雄镜、无人使用过程，也不要改成两人演一场短剧
- 不要拿掉她的自我介绍。产品、店招、Logo 只出现在她已经拍到的地方

## 提取

- 角色：必须提取出镜人；空数组不合法。样貌与妆造按她出镜的样子，不要改成影棚主持人
- 道具：Logo + 镜头里真正出现的物品。不要把相机、手机、摄录机当成道具
- 场景：她拍到的空间。不要改成产品台面空镜，也不要只有影棚口播台

## 分镜与提示词

- description 要让人看出这是她的 Vlog
- 她出镜的【镜头】写明这是手持镜头的机位：她看着镜头，观众就是镜头，画面里没有相机。台词用「角色名说：「…」」。一个镜头只有一个地方
- 镜头对准的景物，画面就是那些景物。那是切镜。下一段【镜头1】必须切回她，接上她刚才那句的反应
- 原稿结尾要观众做的每一件事，都由她对镜头说完，不要改成空镜、字幕板，或只留其中一件
- 情绪线短：对镜头开场 → 切到现场 → 切回反应 → 对镜头收束。按故事顺序，不超过时长上限的同一段出镜留在一段。超过上限就拆到下一个分镜，不要为了同一场景硬放在一段
- 视频提示词引用 `@出镜人`；现场里真正入画的物品才写 `@道具名` `@品牌Logo`。不要写她拿着相机，也不要把切镜改成第三人称跟拍

## 按 ad_angle

角度只决定她这条 Vlog 的重心，不能改掉上面的拍法。

- `street_find` / `food_tour` / `shop_walk`：从她所在的街头或店外讲起，再把镜头给到店内或她正在看的东西
- `host_try` / `explain_cutaway` / `step_vlog`：她边讲边把镜头给到示范，再切回她
- `share_reco` / `visit_cta` / `invite_vlog`：她对镜头完成推荐、看地址或转发
- `selfie_vlog` / `first_try_vlog` / `honest_vlog`：自拍口播，反应留在她脸上
- `day_vlog` / `maker_vlog` / `place_vlog` / `event_vlog`：她串起一天、制程、场地或现场，切镜后回到她

## 禁止

- 产品宣传的空镜集锦、短剧宣传的第三人称冲突
- 把她的口播改成旁白配画面
- 为了电影感重写她没拍的过场
- 为了戏剧性编造品牌名、竞品名、医学效果
- 把「手持镜头」画成手里的设备
