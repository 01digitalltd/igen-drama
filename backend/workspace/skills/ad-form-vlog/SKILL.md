# 形式：Vlog

仅当 `ad_form=vlog` 时生效。这不是产品空镜，也不是第三人称短剧。

## 核心

主角是**拿着镜头的出镜人**。她看着观众说话。厨房、食物、店内、产品是她切过去的画面，下一段必须切回她。

## 改写

- 保留原文的 Vlog 顺序：开场对镜头介绍、切到现场、切回她的反应、结尾对镜头说地址／转发／到店
- 手持、自拍、对着观众讲写进动作。这是出镜动作，不是景别，不要删掉
- 台词是她对观众说的：`角色名：（对镜头）…`。不要改成画外「旁白：」
- 不要改成产品空镜、包装英雄镜、无人使用过程，也不要改成两人演一场短剧
- 不要拿掉她的自我介绍。产品、店招、Logo 只出现在她已经拍到的地方

## 提取

- 角色：必须提取出镜人。样貌与妆造按她出镜的样子，不要改成影棚主持人
- 场景：她拍到的街头、厨房、座位、店内。不要改成产品台面空镜
- 道具：她手里或镜头里真正出现的食物、饮品、包装；另加品牌 Logo

## 分镜

- description 要让人看出这是她的 Vlog
- 她出镜的【镜头】写明手持或自拍、看着镜头，台词用「角色名说：「…」」
- 厨房、食物、店内是切镜。下一段【镜头1】切回她，接上她刚才那句的反应
- 结尾的地址、转发、到店仍由她对镜头说完，不要改成空镜或字幕板
- 不要改成回忆、慢镜或第三人称跟拍

## 按 ad_angle

角度只决定她这条 Vlog 的重心，不能改掉上面的拍法。

- `street_find` / `food_tour` / `shop_walk`：从她所在的街头或店外讲起，再把镜头给到店内或食物
- `host_try` / `explain_cutaway` / `step_vlog`：她边讲边把镜头给到示范，再切回她
- `share_reco` / `visit_cta` / `invite_vlog`：她对镜头完成推荐、看地址或转发
- `selfie_vlog` / `first_try_vlog` / `honest_vlog`：自拍口播，反应留在她脸上
- `day_vlog` / `maker_vlog` / `place_vlog` / `event_vlog`：她串起一天、制程、场地或现场，切镜后回到她

## 禁止

- 产品宣传的空镜集锦、短剧宣传的第三人称冲突
- 把她的口播改成旁白配画面
- 为了电影感重写她没拍的过场
