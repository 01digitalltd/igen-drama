# 目的：资讯教育

仅当 `ad_purpose=edu_info` 时生效。目标是**讲明白一件事**，品牌是可信来源，不是硬推销。

## 结构（约 20–45 秒）

| 场次 | 功能 |
|---|---|
| S01 问题 | 一个具体疑问、误区或「你可能不知道」 |
| S02 讲解 | 用步骤、对比或原理把答案讲完 |
| S03 记住 | 收成一句可带走的结论 |
| S04 收束 | Logo 可见 + 轻 CTA（了解更多/看说明），不要叫卖倒计时 |

语气像老师或懂的朋友，不要导购腔。产品只在能说明知识点时入画。

## 按 ad_angle 执行

### 人物讲解

- `expert_talk`：专家一次讲清楚，少道具，重口播逻辑
- `step_lesson`：逐步教学，一步一场或一步一个动作
- `myth_bust`：先摆错误说法，再纠正
- `faq`：一问一答，问句要短
- `compare_teach`：A vs B 对比说明差异，不要贬低虚构竞品

### 产品宣传

- `how_it_works`：原理/机制可视化，产品当教具
- `feature_tour`：按功能点巡览，一点一场
- `spec_story`：规格、成分、参数用特写讲清
- `before_after`：使用前后画面对比，旁白点明变化

### 短剧宣传

- `mistake_story`：角色先做错，再被纠正或自己学会
- `peer_teach`：角色互相教一个知识点，产品可当教具
- `cliff_lesson`：短剧悬念开场，中段揭晓知识，不要留到下集

## 禁止

- 一上来就促销、倒计时、买一送一
- 把知识点写成连续剧
- 虚构研究数据或医学结论
