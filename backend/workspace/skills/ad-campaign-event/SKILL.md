# 目的：活动档期

仅当 `ad_purpose=campaign_event` 时生效。目标是让人知道「现在有活动」并行动。

## 结构（约 10–20 秒，更短更密）

| 场次 | 功能 |
|---|---|
| S01 档期 | 什么活动、为什么现在 |
| S02 主物 | 主商品、礼盒或活动现场 |
| S03 截止 | 时间压力（用户没给日期则写「活动期间」） |
| S04 行动 | 强 CTA + Logo |

节奏快。不要慢慢讲品牌故事。

## 按 ad_angle 执行

### 人物讲解

- `host_announce`：主持人宣布档期
- `countdown_talk`：倒计时/限时口播
- `event_invite`：邀请参加活动或直播

### 产品宣传

- `key_visual`：主视觉/礼盒档期画面
- `bundle_show`：组合商品展示
- `flash_cuts`：快剪促销画面，每切对应一句利益

## 禁止

- 编造截止日期、折扣数字
- 把档期片拍成 40 秒品牌形象片
