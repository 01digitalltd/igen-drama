# 形式：短剧宣传

仅当 `ad_form=drama_promo` 时生效。

## 核心

用 **15–30 秒微型短剧** 带出卖点或知识点。要有人物、冲突、转折，产品或品牌是转折点，不是开场导购。

这不是「短剧项目」。不要写多集、不要留「下集预告」、不要加无关爱情线拖时长。一场广告讲完一个节拍。

## 改写

- 至少两名有互动的角色，或一名角色与明确障碍（迟到、搞砸、被拒绝）
- 开场先进入情节，不要对镜头自我介绍（那是人物讲解）
- 产品/门店/知识在中后段作为解围、信物或揭晓，不要第一秒就举包装喊卖
- 对白是角色之间说的，少用「旁白讲功能」
- 片尾仍要品牌露出（道具、店招、片尾板），可接一句轻或强 CTA，视目的技能而定

## 提取

- 角色：必须提取出镜人物；空数组不合法
- 道具：Logo + 推动情节的主产品（信物、解围物）
- 场景：故事发生的空间（家、店、街头），不要只有影棚口播台

## 分镜与提示词

- 过半段落绑定角色 `character_ids`；解围场绑定主产品
- description 写角色动作与对白：「角色名说：「…」」
- 情绪线短：钩子冲突 → 转折 → 收束，不要按长剧集拆场
- 视频提示词引用 `@角色名` `@主推产品` `@品牌Logo`

## 禁止

- 写成可连载的短剧大纲
- 对镜头讲课或纯产品空镜集锦（那是另外两种形式）
- 为了戏剧性编造品牌名、竞品名、医学效果
