# 广告推广共用规范

本技能只在项目 `project_category` / `genre` 为 `ad_promo` 时生效。短剧项目**完全忽略本文件**。

节拍结构、出镜方式以同时注入的 **目的技能** 和 **形式技能**（ad-form-talent / ad-form-product / ad-form-drama）为准。本文件只管全类型共用规则。

广告项目复用同一条生产管线（改写 → 提取 → 提示词 → 分镜 → 成片）。格式仍用短剧的场景头，方便后续提取与分镜工具复用。

## 品牌与 Logo（全流程硬规则）

1. **公司 Logo 是必备资产**，以道具形式存在：`name=品牌Logo`，`type=品牌Logo`。
2. **禁止 AI 生成或重绘 Logo。** 优先使用品牌设定已上传的官方原件。没有 `image_url` 时不要编造图案。
3. 提取道具时若项目还没有 Logo 道具，必须补上 `品牌Logo`；已有则复用并关联到当前集。
4. 为 Logo 道具写最终提示词时：不要产出可拿去生图的白底单品词。应明确「使用品牌设定已上传的官方 Logo，禁止重绘」。
5. 分镜里凡是品牌露出必须绑定 Logo 道具的 `prop_ids`。
6. 不要发明品牌名、口号、包装文字。用户没给的信息留空。
7. 不要把价格、电话、网址烧成画面大字（改口播/旁白）。

## 格式（必须遵守）

- 场景头：`## S编号 | 内景/外景 · 地点 | 时间段`
- 动作描写：可见画面，不写镜头语言
- 对白：`角色名：（状态）台词`；口播可写成「旁白：（状态）文案」
- 品牌露出写成包装、店招、片尾板或讲解人身边的实物，不要写「屏幕弹出大字 Logo」

## 禁止事项

- 把广告项目写成连续短剧、加无关爱情线
- AI 发明或美化官方商标
- 在短剧项目中套用本文件
- 忽略已注入的目的技能 / 形式技能 / `ad_angle` / 创意情节库技能
