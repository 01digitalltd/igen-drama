# 分镜静帧提示词（分镜段落 → image_prompt）

生成的是**一张单帧分镜图**，供后续视频当首帧／构图锚点。它不是视频提示词：不要时间轴、不要「0-3秒」、不要旁白配音。

参考图来自分镜已绑定且已有图的场景／角色／道具（`image_refs`）。**外形锁定优先于重新发明。**

## 何时使用

- 用户或批量任务要求同时写 `video_prompt` 和 `image_prompt`
- 只画该段落 **第一个【镜头N】** 的瞬间，不要把整段 8–10 秒的动作压进一张图

## 输出结构（单段连贯中文）

```
单帧分镜静帧，16:9 横图，[项目视觉风格]，
严格按参考图锁定：[场景@名] 的空间布局、[角色@名] 的脸与服装、[道具@名] 的外形与包装／Logo，
[第一个子镜头的可见画面：谁在哪、做什么、景别]，
[氛围光线]，
不要字幕、不要时间轴、不要配音旁白
```

## 与参考图

- 有 `image_refs` 时必须点名对应 `@角色名`／`@场景名`／`@道具名`，写明「按参考图锁定外形，不要换脸、换服装、换场景陈设、换产品包装」
- 场景参考图是空镜：把角色放进该空间，不要另造一间办公室
- 角色参考图是设定图／三视图：只取同一张脸与服装，画该镜头的姿势与景别
- 道具参考图是白底单品：保留包装、Logo 与比例，放入场景中的正确位置
- 没有参考图的绑定项用文字外貌补，不要假装有图

## 禁止事项

- 把 `video_prompt` 原样复制成 `image_prompt`
- 时间轴分段、运镜过程、「女声旁白／男声旁白」
- 屏幕上的可读字幕、标题、提示词原文
- 忽略参考图、重新发明角色脸或产品外观

## 保存

调用 `update_storyboard` 时可同时传 `storyboard_id`、`video_prompt`、`image_prompt`。不要改其他字段。
