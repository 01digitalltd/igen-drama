# 分镜静帧 = 这段影片的第 0 帧

这张图会钉成这段影片的第一帧。只画 **镜头 1** 动作刚开始的那一瞬间。镜头 2、镜头 3 留在 `video_prompt` 的时间轴里，不要画进这张图。

画幅跟项目（横图、竖图或方图），不要另写一套比例。

请求里资产图会 **写在文字前面**：`contents.parts` = 第 1 张图、第 2 张图…然后才是 `image_prompt`。Gemini 只认「第一张图 / 第二张图」，不认 MiniMax 的 `@角色名`，也不认视频 Omni 的 `<IMAGE_REF_N>`。

它不是视频提示词：不要时间轴、不要「0-3秒」、不要旁白配音。

## 何时使用

- 用户或批量任务要求同时写 `video_prompt` 和 `image_prompt`
- `video_prompt` 用整段 description；`image_prompt` 只用镜头 1

## 输出结构（单段连贯中文，给 Gemini 看）

`image_refs` 顺序固定：场景空镜 → 角色设定图 → 道具单品。文字编号必须跟这个顺序一致。

```
这是同一部短片里的一镜，不是另一部影片。全片保持[项目视觉风格]。
这是这段影片的第 0 帧，只画镜头 1 动作刚开始的瞬间。不要画镜头 2 及之后。
若项目是 3D Chibi：人物头身比约 1:2、头大身小、四肢短圆、盲盒风三维，场景与道具也是同款圆润卡通三维，禁止电影质感真人。
根据前面按顺序附上的参考图，生成一张单帧分镜静帧。
第一张图是场景空镜（[名]）：只用它的空间布局与陈设，把人物放进这个空间，不要另造场景。
第二张图是角色设定（[名]）：必须保持同一张脸、发型与服装，只改镜头 1 的姿势与景别，禁止换人换脸。
第三张图是道具（[名]）：只有镜头 1 用到它才放进画面，保留包装、Logo 与比例。
（如有）第 N 张图是本片已生成的分镜：保持同一画风、色温、服装；只改镜头 1 的动作与景别。
画面：[镜头 1：谁在哪、刚开始做什么、景别]
光线：[镜头 1 的氛围；色温必须跟全片一致]
不要把对白烧成字幕、不要时间轴、不要配音旁白。画面里的招牌、包装说明、屏幕、字卡用【分镜图文字】指定的文字。
```

没有某类参考图就删掉对应那一行，不要假装有图。

## 硬约束

- 只使用镜头 1 的人物、地点、动作和道具。后面镜头里的厨房、装盘、特写、转场不要出现
- 全部分镜静帧必须像**同一部短片**：同一画风、色温、镜头质感、服装与发型。禁止每镜另造一张脸、一套衣服或另一种媒介
- 若前面附上「本片已生成分镜」，只改镜头 1 的动作、景别与机位，不要换成另一部电影
- 有人物图时，脸必须来自「第 N 张图」那张像素，不要用外貌文字重新发明一张脸
- 角色参考图可能是三视图／设定图：只取同一张脸与服装
- 场景参考图是空镜：不要另造一间办公室
- 没有附上的绑定项才用文字外貌补
- 禁止只写 `@角色名` 或 `<IMAGE_REF_N>` 当锁定方式

## 禁止事项

- 把 `video_prompt` 原样复制成 `image_prompt`
- 把镜头 2 及之后画进这张静帧
- 把「手持镜头」「自拍」「对着镜头」画成她拿着相机、手机或稳定器。只有镜头 1 这样写时，那才是机位：观众就是镜头，她看着镜头
- 时间轴分段、运镜过程、「女声旁白／男声旁白」
- 屏幕上把整段对白烧成字幕
- 画面文字用错文字：粤语或台湾国语写成简体，大陆普通话写成繁体
- 忽略前面附上的人物／场景／道具图

## 保存

调用 `update_storyboard` 时可同时传 `storyboard_id`、`video_prompt`、`image_prompt`。不要改其他字段。落库时仍以镜头 1 重写静帧，模型如果写进了后面的镜头也会被盖掉。
