# 分镜静帧提示词（分镜段落 → image_prompt）

生成的是**一张单帧分镜图**，供后续视频当首帧／构图锚点。生图时会把 `image_refs` 里的资产图按相同顺序当作输入图上传（图生图），不是纯文字想象。

它不是视频提示词：不要时间轴、不要「0-3秒」、不要旁白配音。

## 何时使用

- 用户或批量任务要求同时写 `video_prompt` 和 `image_prompt`
- 只画该段落 **第一个【镜头N】** 的瞬间，不要把整段 8–10 秒的动作压进一张图

## 输出结构（单段连贯中文）

有 `image_refs` 时必须用 **参考图N**（N 从 1 起，对应 `image_refs` 的 index+1 / `<IMAGE_REF_0>` = 参考图1），不要只写 `@角色名`——生图模型看不到 MiniMax 的 @ 名字，只看得到按序上传的图。

```
单帧分镜静帧，16:9 横图，[项目视觉风格]，图生图合成。
参考图1（场景空镜：[名]）只取空间与陈设；
参考图2（角色设定：[名]）必须用同一张脸、发型与服装，禁止换人换脸；
[第一个子镜头的可见画面：谁在哪、做什么、景别]，
[氛围光线]，
不要字幕、不要时间轴、不要配音旁白
```

## 与参考图（硬约束）

- `image_refs` 顺序固定：场景空镜 → 角色设定图 → 道具单品。编号必须跟这个顺序一致
- 角色参考图是设定图／三视图／上传的人物图：只取同一张脸与服装，改姿势与景别，**不要重新发明一张脸**
- 场景参考图是空镜：把角色放进该空间，不要另造一间办公室
- 道具参考图是白底单品：保留包装、Logo 与比例
- 没有 `image_refs` 的绑定项才用文字外貌补，不要假装有图
- 禁止把视频技能的 `@名字` 当成唯一锁定方式；有参考图就必须写「参考图N」

## 禁止事项

- 把 `video_prompt` 原样复制成 `image_prompt`
- 时间轴分段、运镜过程、「女声旁白／男声旁白」
- 屏幕上的可读字幕、标题、提示词原文
- 忽略已上传的人物／场景／道具图，重新发明角色脸或产品外观

## 保存

调用 `update_storyboard` 时可同时传 `storyboard_id`、`video_prompt`、`image_prompt`。不要改其他字段。
