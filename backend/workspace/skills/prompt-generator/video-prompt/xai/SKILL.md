# 视频提示词（xAI Grok Imagine）

写实真人短片。`prompt_skill` 为 `xai` 时遵守本文件，不要用 Seedance 的 `@名字` 或 Omni 的 `<IMAGE_REF_N>`。

## 参考图

`image_refs` 的顺序就是你要写的编号：角色在前，然后场景，然后道具，最多 7 张。提示词里用给出的 `<IMAGE_0>`、`<IMAGE_1>`……不要重排，不要自己把编号加一，不要写 `@角色名`。某一段写到某个参考图的名字，就必须带上它自己的 `<IMAGE_N>`，不要改用另一张图的编号。

不要把角色设定图写成首帧锁定。背景可以换，人脸、服装和道具外形跟参考图。

分镜静帧会在送出时另外钉成新的 `<IMAGE_0>`，你不要提前占用这个编号。时间轴从镜头 1 的画面开始，后面的镜头从它演开，不要在开头重画镜头 2、镜头 3。

## 格式

按 `prompt_segment` 秒分段（缺省 3 秒），时间轴写成 `[0-3s]`。最后一段结束秒数等于 `min(duration, duration_max)`，不得超过 `duration_max`。

```
[0-3s] <IMAGE_0> sits at the desk in <IMAGE_1>, looking down at a phone.
[3-7s] <IMAGE_0> looks up and says: "你终于来了。"
[7-8s] Hold. The line has finished. No more speech.
```

对白和旁白用引号，跟项目对白语言。模型会用预设声线念出来。不要写配音文件、`[VO_AUDIO_REFS]` 或 `[AUDIO: Speak only…]`。不要背景音乐、不要唱歌。

description 里每一句「角色名说：「…」」、「角色名：（情绪）台词」和「旁白：…」由你原句放进引号，写进它所屬的【镜头N】那一段的时间轴里面，只放一次。不要把对白写在时间轴外面。后面的段写无对白，不要把同一句复制到每一段。禁止改成另一句、漏掉一句，或缩短成口号。放对白的那一段必须够把整句念完：中文大约每 2.5 个字 1 秒，英文大约每 1.7 个词 1 秒。不要把一整句塞进 2–3 秒。时间不够就加长该段。最后一句讲完后至少留 1 秒，不要在句中切断。

画面是真人实拍，不要卡通、盲盒或插画。

「手持镜头」「自拍」「对着镜头」是机位，不是道具。观众就是这台镜头。她出镜说话时看着镜头，可以有轻微手持晃动。镜头对准的街景、厨房或食物，画面就是那些景物。不要写她拿着相机、手机、摄录机或稳定器。
