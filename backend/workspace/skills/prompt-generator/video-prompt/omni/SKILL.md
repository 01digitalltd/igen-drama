# Gemini Omni 视频提示词（分镜段落 → video_prompt）

仅当 `read_storyboard_context.video_generation.prompt_skill` 为 `omni`（provider/model 含 gemini / omni）时遵守本技能。其他模型改用父技能 `video-prompt`（Seedance 格式）。

根据单个分镜段落的 description（含【镜头N】子镜头与台词/旁白）/ atmosphere / duration，以及 `video_generation` 时长上限，生成驱动 **Gemini Omni Flash**（`gemini-omni-1.1-flash` / `gemini-omni-flash-preview`）的 `video_prompt`。Omni 同时处理文本、图像并自带音轨：提示词要同时写清画面、运镜、光线、情绪，以及对白/环境声/音乐。

**一个分镜段落 = 一次视频生成任务，时长不得超过 `duration_max`（Omni 上限 10 秒）**。段内允许切镜，但**全程不跨场景**、不闪回。

## 格式

按 `video_generation.prompt_segment` 秒为一段（缺省 3 秒），每段单独一行。时间码用 Omni 原生写法 `[起-止s]`，连续衔接（无重叠、无空缺）。最后一段的结束秒数必须等于 `min(duration, duration_max)`。

```
[0-3s] @咖啡厅，近景固定镜头，@小明低头看手机，手指反复敲桌面。无对白。音效：雨打窗、钟滴答。暖黄台灯，焦躁空气。
[3-6s] 切到门口全景，门铃响，@小红推门走入，带进一阵冷风。无对白。音效：门铃、冷风灌入。
[6-9s] 切回中景，@小红走向小明坐下。小明说：「你终于来了。」对白清晰可辨。音效：椅子轻响。保持同一咖啡厅。
```

不要写成 Seedance 的 `0-3秒：` 行首格式。

## 与分镜描述的映射

`description` 是 video_prompt 的唯一内容来源：

- 每个 `【镜头N】` 映射为 **1-2 个连续分段**，顺序一致、不遗漏、不合并、不新增子镜头
- 台词/旁白从对应 `【镜头N】` 内的「角色名说：「…」」「旁白：…」提取；**不要创作 description 之外的新台词**
- 画面动作以 `description` 为准；`atmosphere` 只补光线、色调、氛围与环境声

## 段内结构

每一段按此顺序（可省略无内容的项，画面与音频必须有）：

**`[起-止s]` ＋ 场景@引用 ＋ 景别/运镜 ＋ 角色@引用＋主体动作·表情 ＋ 对白/旁白 ＋ 音频 ＋ 氛围光线**

- **第一段必须建立空间**：场景 + 机位 + 角色位置与状态
- **切镜**：Omni 默认会自行切镜讲故事。短剧需要对齐分镜时，在切镜段开头写「切到/切回」并重交代景别与主体；切镜点对齐 `【镜头N】`
- **单镜连续**：若该 `【镜头N】` 跨多段且不能切，在这些段写「同一连续镜头、不切镜、unbroken continuous shot」
- **景别/运镜**：每段一个镜头状态（近景/中景/全景/特写；固定/推/拉/摇/跟）
- **动作**：每段一个主动作，动词具体可见
- **情绪全部转为可见描写**：不要「他很伤心」，写成「他低下头、手指攥紧杯沿、呼吸变重」
- **时机**：可用自然语言标事件点，如「3 秒后她走进画面」「每 2 秒切一个新景别」。时间码里的 0s 是本段视频开头，不是整集开头

## 音频（Omni 必写）

Omni 会自动配音轨。不写音频时模型会自行发明对白或配乐，必须显式控制：

- **有对白**：写「角色名说：「台词」」，并加「对白清晰可辨」。台词改成项目对白语言的自然口语，意思与 description 一致；3 秒念不完拆到多段
- **无对白**：该段写「无对白」或「No dialogue」，避免模型加台词
- **旁白**：写「旁白：内容」
- **环境声 / 动作音**：雨、门铃、脚步、杯沿碰撞等，与画面同步
- **配乐**：仅当 atmosphere 明确需要时写（如「低沉室内钢琴」）；不要无中生有的高能电子乐
- **不要的声音**写进正文：无对白、无旁白、无额外音效、无画外解说

## 引用规则

落库提示词仍用 `@名字`（编辑器提及）。生成时会把 `@小明` 换成 Omni 的 `<IMAGE_REF_N>`，绑定对应参考图。不要自己写 `<IMAGE_REF_N>`、`<FIRST_FRAME>`、`<LAST_FRAME>` 或 `[# Sources]`。

- `@场景名` / `@角色名` / `@道具名` — 必须与列表名字完全一致，不要缩写
- **每段至少一个 @ 引用**；角色出场的段必须 @ 该角色
- 只引用该分镜已绑定的场景/角色/道具
- 参考图是形象/场景锚点，不是视频第一帧；不要提示「从这张静帧开始播」

## 画面与质量

- 写清机位、光线、情绪；细节越具体（微表情、手部、尘埃、布料质感）画面越稳
- 背景里会出现的可读文字必须写死内容（路牌、店招、车牌），否则 Omni 会乱写
- 负向约束写在正文里（系统不支持 negative prompt），例如「不要字幕、不要水印、不要额外角色」
- 物理与常识可写进动作（雨会湿衣、玻璃会反光），但剧情仍以 description 为准
- 英文未评估；画面/运镜/氛围跟写作语言，对白跟项目对白语言

## 时间轴规则

- 段数 = duration ÷ prompt_segment（向上取整），各段相加等于 min(duration, duration_max)，不得超过 duration_max（Omni 最长 10 秒）
- 节奏：第一段建立 → 中段推进 → 末段落到结果或情绪点

## 禁止事项

- 跨场景切换、闪回
- 引用列表之外的场景/角色名
- 抽象心理描写、文学化比喻
- 把整段提示词都改成对白语言
- 把对白写成屏幕字幕或标题（对白走音轨；屏幕文字只用于场景里真实存在的招牌等）
- 使用 Seedance 的 `0-3秒：` 行首格式
- 为 Omni 编写编辑/续写指令（「Make the violin invisible」「Extend this video」）——本技能只生成全新片段

## 保存

调用 `update_storyboard` 仅更新该分镜段落的 `video_prompt` 字段，不要改动其他字段，不要重新拆分整集。
