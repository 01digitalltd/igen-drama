# 道具最终提示词（白底单品）

生成的是一张白底单品图：画面中只有道具本身，孤立放置在纯白背景上，没有其他物品、人物、场景或手部持握。

**画风必须跟项目视觉风格一致。** 用户消息里的【视觉风格】要写进提示词开头。3D Chibi 时整张是 Q 版三维产品渲染（保留可辨识外形、包装与 Logo），禁止真人产品摄影、禁止实拍静物棚拍。

三条硬性要求：
1. **外形可辨识**——保留比例、包装与 Logo 布局；画风跟项目走，不要为了写实而丢掉风格
2. **边缘完整**——道具整体完整入镜，四周留白，任何部分都不得被画面边缘裁切
3. **背景不承载任何叙事内容**——纯白背景只是衬底，不带场景感、不带情节暗示、不带装饰元素

## 输出结构（按此顺序组装单段连贯中文）

```
单品产品图，白底静物，[道具名 + 材质/颜色/形状/大小 + 新旧程度与磨损细节]，
孤立放置在纯白背景上，居中完整入镜，边缘完整无裁切，
背景纯净不承载任何叙事内容，无其他物品、无人物、无场景，
跟项目视觉风格同一套画风
```

## 生成规则

- 以道具 `name`（名称）与 `description`（物品外貌）为核心：材质、颜色、形状、大小、新旧程度、磨损痕迹等物理细节**逐项落地**，这是道具辨识度的来源
- 微俯视 3/4 视角（同时看清顶面与侧面）；扁平道具（纸张、证件、照片）用正俯视平铺
- 单品居中完整呈现，四周留白，边缘完整，不要裁切道具主体
- 只描写物品本身，不要提及剧情、角色或用途（背景与画面都不承载叙事内容）
- 输出必须是纯中文，并写进项目视觉风格。3D Chibi 时做成 Q 版三维产品渲染，不要写成真人产品摄影
- **不要**"电影质感"、"产品摄影棚拍"类词汇

## 禁止事项

- 手部持握、人物、其他物品、场景环境入镜
- 包装、底座、展示架（除非它就是道具本体的一部分）
- 文字、水印、签名（道具本体上印刷的文字图案可以保留并描述）
- 环境反光、彩色光
- 夸张透视、边缘裁切；写实项目不要变形，3D Chibi 项目按 Q 版画风渲染但仍要认得出来

## 保存

调用 `save_prop_final_prompt`：prompt 参数不含风格词，**项目视觉风格由工具自动注入到最终提示词的最前方**。
