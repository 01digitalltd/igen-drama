# 手法词汇

这些是可选的手法类型，不是必须套用的菜单，也不是成片。从用户故事主干自己发明一个主导手法。只有该手法能服务用户自己的冲突时才借用，否则按五拍原创。一支片子只用一个主导手法。不要抄行业、角色、门店或 CTA。

- 問題怪獸：把困扰具象成会变大的阻碍，解围出现后阻碍缩小。
- 倒轉結局：先看见改变后的状态，再倒回冲突，最后回到那个状态。
- 最後三秒拯救：冲突被倒数压到最后一刻，解围出现时倒数停下。
- 傳統方法與專業方法賽跑：旧办法一路碰壁，另一条路先看清再行动。
- 未來的自己突然出現：较从容的未来版本出现，陪现在的自己面对压力。
- 微型團隊進入房屋：人被带进问题发生的空间内部，在里面改好再回到外面。
- 多重分身失控：同一个人分裂成互相矛盾的做法，理清之后合成一个方向。
- 身體控制室：进入一套发出警示的内部系统，跟进之后警示转为正常监察。
- 神秘盒子：一个锁着的问题被逐格打开，猜错之后最后一格才露出真正的下一步。
- 骨牌效應：一个开头失误连着撞倒后面的麻烦，一份完整计划把链条扶正。
- 兩個平行世界：同一处境分成逃避和面对两条线，逃避的一边最终走向面对。
- 身體不適上法庭：多个可能原因互相指责，评估出场后停止自行猜测。
- 恐怖片誤導：先用紧张误导，揭晓后只是一个可处理的小麻烦。
- 選擇門：两扇门，一扇是继续乱猜，一扇是寻求合适的下一步。
- 無限循環工作日：同一天的困扰反复循环，直到采取下一步，日子才往前走。
