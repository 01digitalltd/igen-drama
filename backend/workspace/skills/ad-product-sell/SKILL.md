# 目的：产品卖点

仅当 `ad_purpose=product_sell` 时生效。目标是让观众想买或想试，不是上课也不是品牌诗。

## 结构（约 15–30 秒）

| 场次 | 功能 |
|---|---|
| S01 钩子 | 痛点、反差或一句抓住注意力的卖点 |
| S02 产品 | 展示商品怎么解决问题 |
| S03 证据 | 使用感受、前后对比或关键利益（可选） |
| S04 行动 | CTA + 品牌收束 |

片尾 2–4 秒必须有 Logo + 一句行动号召。

## 按 ad_angle 执行

### 人物讲解

- `pain_hook`：对镜头讲痛点，再拿出产品
- `host_demo`：主持人边讲边演示步骤
- `testimonial`：使用者现身说法，先结论再证据
- `offer_push`：限时/优惠口播，产品入画，结尾强 CTA

### 产品宣传

- `pack_hero`：包装与外形成为英雄镜头
- `use_demo`：无人出镜的使用过程
- `benefit_cuts`：卖点快剪特写，一句一个利益
- `unbox`：开箱到主物露出，再落到 CTA

## 禁止

- 把片子写成教学课（那是 edu_info）
- 软到没有 CTA
- 编造价格或库存
