# 目的：品牌形象

仅当 `ad_purpose=brand_image` 时生效。目标是留下气质与信任，不是讲完功能表。

## 结构（约 20–40 秒）

| 场次 | 功能 |
|---|---|
| S01 氛围 | 质感、场所或一句理念 |
| S02 内核 | 工艺、创办人、价值观或生活里的品牌物件 |
| S03 符号 | Logo 或标志性包装自然入画 |
| S04 余韵 | 轻收束，CTA 最多一句「认识我们」 |

节奏可慢一点。少对白也可以，但形式技能仍要遵守（人物讲解必须有人讲；短剧宣传必须有微型冲突）。

## 按 ad_angle 执行

### 人物讲解

- `founder_story`：创办人/代言人叙事
- `values_talk`：理念口播，画面配品牌场景
- `craft_tour`：職人讲述制程

### 产品宣传

- `cinematic_pack`：产品影像诗，光影材质优先
- `origin_process`：产地/制程空镜
- `lifestyle_set`：生活场景里的品牌物件

### 短剧宣传

- `slice_of_life`：一段生活切片，品牌自然出现
- `origin_vignette`：微故事讲品牌从哪来，当场收束
- `craft_scene`：制程融入一段人物故事

## 禁止

- 快剪导购、限时优惠、大声 CTA
- 把片子写成产品说明书
