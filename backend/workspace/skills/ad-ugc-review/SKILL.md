# 目的：UGC / 真实测评

仅当 `ad_purpose=ugc_review` 时生效。看起来像用户自己拍的，不要影棚广告腔。

## 结构（约 15–30 秒）

| 场次 | 功能 |
|---|---|
| S01 开场 | 第一人称：「我用了…」「刚拆开…」 |
| S02 过程 | 使用、开箱或一天里的出镜 |
| S03 判断 | 优点，可带一句真实限制（不要编差评） |
| S04 收束 | 口头推荐 + Logo（包装或身边实物） |

画面允许手持、桌面杂物。不要写成精修 TVC。

## 按 ad_angle 执行

### 人物讲解

- `selfie_review`：自拍口播测评
- `first_use`：开箱第一印象
- `honest_proscons`：优缺点直说，结尾仍推荐

### 产品宣传

- `handheld_demo`：手持跟拍使用
- `overlay_review`：产品特写 + 旁白点评（旁白不烧字幕）
- `day_in_life`：一天里产品多次出镜

## 禁止

- 影棚灯光语言、专业主持人腔
- 编造具体测评分数
- 贬低真实竞品品牌名
